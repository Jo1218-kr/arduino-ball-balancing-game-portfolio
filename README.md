# Ball Balancing Game 및 맞춤형 PCB 설계 | Embedded Systems II Course Project

Utah Valley University의 Embedded Systems II 팀 프로젝트입니다. 플레이어가 조이스틱으로 미로판을 기울여 구멍을 피해 공을 결승점까지 이동시키는 게임을 제작했습니다.

## 참여 역할

조선신은 팀원들과 게임 장치를 제작하고 맞춤형 PCB의 설계와 제작에 참여했습니다.

## 구현 결과

팀은 Fritzing으로 브레드보드 배선을 회로도와 PCB 레이아웃으로 옮겼습니다. 제작한 기판에 부품을 납땜하고 조이스틱과 서보모터 두 개를 연결했습니다. Arduino 제어 회로는 조이스틱의 두 축 입력을 각각 모터 각도로 변환해 미로판의 기울기를 조절합니다.
